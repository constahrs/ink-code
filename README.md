# C++ 学习资源库 (Ink-Code)

这是一个全面的C++学习资源库,包含基础知识点和实践项目。

## 📚 目录结构

### 基础知识点 (basics/)

学习C++编程的基础知识和核心概念:

1. **[变量和数据类型](basics/01-variables-and-datatypes.md)** - 学习C++的基本数据类型和变量声明
2. **[运算符](basics/02-operators.md)** - 算术、逻辑、比较和位运算符
3. **[控制结构](basics/03-control-structures.md)** - if语句、循环和switch语句
4. **[函数](basics/04-functions.md)** - 函数定义、参数传递、递归和Lambda表达式
5. **[数组和指针](basics/05-arrays-and-pointers.md)** - 数组操作、指针基础和动态内存
6. **[面向对象编程基础](basics/06-oop-basics.md)** - 类、对象、继承、多态和封装

### 实践项目 (projects/)

通过实际项目巩固所学知识:

1. **[简单计算器](projects/01-calculator/)** - 基本的四则运算计算器
   - 功能: 加减乘除、错误处理、持续运算
   
2. **[学生管理系统](projects/02-student-management/)** - 学生信息的增删改查
   - 功能: 添加、删除、修改、搜索学生信息，计算平均分
   
3. **[文件操作项目](projects/03-file-operations/)** - 文件读写和笔记管理
   - 功能: 文件读写、笔记管理、内容搜索

## 🚀 快速开始

### 环境要求

- C++ 编译器 (GCC 或 Clang)
- C++11 或更高版本

### 编译和运行项目

```bash
# 示例: 编译计算器项目
cd projects/01-calculator
g++ -o calculator calculator.cpp
./calculator
```

## 📖 学习路径

### 初学者路径

1. 从基础知识开始，按顺序学习 `basics/` 目录下的内容
2. 每学完一个知识点，尝试完成文档中的练习题
3. 学习完基础后，从简单的项目开始实践

### 推荐学习顺序

```
变量和数据类型 → 运算符 → 控制结构 → 函数 → 
数组和指针 → 面向对象编程 → 实践项目
```

## 💡 学习建议

- **动手实践**: 不要只看代码，要自己动手写
- **修改示例**: 尝试修改示例代码，观察运行结果
- **完成练习**: 每个知识点后都有练习题，务必完成
- **项目实践**: 学完基础后，务必完成至少一个完整项目
- **扩展功能**: 尝试为项目添加新功能
