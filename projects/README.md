# C++ 实践项目

本目录包含三个实践项目,帮助你巩固C++基础知识。

## 项目列表

### 🧮 [1. 简单计算器](01-calculator/)

**难度:** ⭐ 初级

**知识点:**
- 类和对象
- 函数定义
- Switch语句
- 异常处理
- 循环控制

**功能:**
- 支持加减乘除运算
- 除零错误处理
- 用户友好的菜单界面
- 持续运算模式

**适合人群:** 刚学完基础知识的初学者

### 👨‍🎓 [2. 学生管理系统](02-student-management/)

## 学习建议

### 项目学习步骤

1. **阅读README**: 了解项目功能和要求
2. **分析代码**: 逐行阅读代码,理解实现逻辑
3. **编译运行**: 编译并运行项目,测试所有功能
4. **添加注释**: 为关键代码添加注释,加深理解
5. **扩展功能**: 尝试实现README中建议的扩展功能

### 推荐学习顺序

```
计算器 → 学生管理系统 → 文件操作
```

### 学习重点

#### 项目1 - 计算器
- 理解类的基本结构
- 学会使用异常处理
- 掌握菜单驱动程序的设计模式

#### 项目2 - 学生管理系统
- 学习数据管理的基本操作(CRUD)
- 理解如何设计和使用容器
- 掌握搜索和统计算法

#### 项目3 - 文件操作
- 掌握文件读写的基本方法
- 学习数据持久化
- 理解文件流的使用

## 编译和运行

### Linux/Mac

```bash
# 进入项目目录
cd projects/01-calculator

# 编译
g++ -o calculator calculator.cpp -std=c++11

# 运行
./calculator
```

### Windows

```bash
# 使用 MinGW 或 Visual Studio
g++ -o calculator.exe calculator.cpp -std=c++11

# 运行
calculator.exe
```

## 调试技巧

### 常见问题

1. **编译错误**: 检查语法错误,确保使用C++11或更高版本
2. **链接错误**: 确保所有文件都已正确编译
3. **运行时错误**: 使用调试器或添加cout语句跟踪

### 调试命令

```bash
# 使用 GDB 调试
g++ -g -o calculator calculator.cpp
gdb ./calculator

# 或使用 LLDB (Mac)
lldb ./calculator
```

## 最佳实践

### 代码风格
- 使用有意义的变量名
- 适当添加注释
- 保持函数简洁
- 合理缩进代码

### 错误处理
- 验证用户输入
- 使用异常处理
- 提供有用的错误消息

### 代码组织
- 一个类一个文件(对于大项目)
- 使用头文件(.h)和实现文件(.cpp)分离
- 保持main函数简洁
